# Website guide

How to run the site day to day (Pages CMS) and how to take it over (GitHub, domain at Worldbus.ge, Google Business Profile).

- [guide-ka.pdf](guide-ka.pdf): Georgian, for the café staff
- [guide-en.pdf](guide-en.pdf): English

The PDFs are built from `guide-ka.html` and `guide-en.html` (screenshots in `img/`). After editing a source, run `./build.sh` and commit the PDFs.
